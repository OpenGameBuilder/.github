# Learning resources

Shared reading for OpenGameBuilder contributors:

- [C#](csharp.md): language tutorials and reference material.
- [ASP.NET Core](asp-net-core.md): web APIs, hosting, security, and testing.
- [Blazor](blazor.md): components, browser interop, and deployment.
- [Browser DevTools](browser-devtools.md): inspecting pages and network requests.
- [Caddy](caddy.md): HTTPS, reverse proxies, and server configuration.

These pages collect links to upstream documentation. For the application's
prerequisites and supported workflow, use the
[development guide](https://github.com/OpenGameBuilder/opengamebuilder/blob/main/docs/setup/development.md);
for deployment operations, use its
[hosting guide](https://github.com/OpenGameBuilder/opengamebuilder/blob/main/docs/setup/hosting.md).

Versioned Microsoft Learn links retain the .NET 10 view used by the original
collection. Select the documentation version that matches the project you are
working on. A linked topic does not imply that a project implements that feature.
